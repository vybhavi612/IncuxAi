# Student Attendance & Activity Tracking System
Overview

The Student Attendance & Activity Tracking System is a full-stack web application developed to monitor student attendance, GitHub activity, daily task submissions, and productivity analytics. The system provides separate dashboards for students and administrators, enabling efficient tracking of internship or training progress.

Features
Student Dashboard
Student login and authentication
Daily attendance tracking
GitHub activity verification
Daily work/task submission
Task history tracking
Profile management
Attendance status monitoring
Admin Dashboard
View all registered students
Monitor attendance records
Track GitHub activity status
View submitted daily tasks
Productivity analytics dashboard
Student performance monitoring
Date-wise filtering of records
Working hours visualization using charts
