# Student Tracker System

## Overview

Student Tracker System is a web-based application developed to manage student information and attendance efficiently. The project provides an easy way for administrators to monitor student records, manage attendance, and organize data through a simple dashboard interface.

## Objective

The main objective of this project is to simplify student management and attendance tracking using a digital platform. It reduces manual work and improves accessibility of student information.

## Technologies Used

* HTML
* CSS
* JavaScript
* Node.js
* Express.js
* Firebase Firestore
* Firebase Authentication

## Features

* Student Registration
* Student Login
* Admin Login
* Attendance Management
* Student Dashboard
* Firebase Database Integration
* Responsive User Interface

## Working

Students can register and log in to the system using their credentials. The admin can access a separate dashboard to view student details and manage attendance records. All data is stored securely in Firebase Firestore, while authentication is handled using Firebase Authentication.
