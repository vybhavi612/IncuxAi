Intern Management System – MVP
Project Goal
Build a simple Intern Management System that allows:
•	Intern attendance tracking
•	Task assignment by managers
•	Progress monitoring
•	Admin management
The system will have 3 user roles:
1.	Intern
2.	Manager
3.	Admin
________________________________________
Core Features
1. Homepage
Create a landing page with:
•	Intern Login
•	Manager Login
•	Admin Login
________________________________________
2. Authentication System
Intern
•	Create account
•	Login
•	Logout
Manager
•	Login using admin-provided credentials
Admin
•	Full access to system
________________________________________
3. Intern Dashboard
After login, intern should see:
Attendance
•	Present days
•	Absent days
•	Late attendance count
•	Login/logout history
•	Attendance percentage
Attendance should automatically mark when intern logs in.
________________________________________
Tasks
Show:
•	Assigned tasks
•	Task status
•	Deadlines
•	Completed tasks
•	Pending tasks
•	Progress percentage
Intern can:
•	Mark tasks as completed
________________________________________
Profile
Display:
•	Profile photo
•	Name
•	Department
•	Contact details
Intern can edit profile information.
________________________________________
4. Manager Dashboard
Manager should be able to:
•	View all interns
•	Assign tasks
•	Edit/delete tasks
•	Track intern progress
•	View attendance records
________________________________________
5. Admin Dashboard
Admin should be able to:
•	Manage interns
•	Manage managers
•	View all attendance
•	View all tasks
•	Edit/delete user data
________________________________________
6. Database
Store:
•	User accounts
•	Attendance records
•	Tasks
•	Login/logout times
________________________________________
7. Technologies
Frontend:
•	HTML
•	CSS
•	Bootstrap
Backend:
•	Python Flask
Database:
•	SQLite/MySQL
________________________________________
8. Expected Workflow
1.	User opens homepage
2.	User selects login role
3.	Intern logs in
4.	Attendance automatically marked
5.	Manager assigns tasks
6.	Tasks appear in intern dashboard
7.	Intern completes tasks
8.	Admin monitors system
