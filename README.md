# IncuxAi

Attendance Tracker

Functionalities

- Register
- Login
- Logout


Features

- Each user must be uploading a profile photo while registering
- Track the working time - Calculated using the time between Login and Logout
- Dashboard which displays if you have logged in on time or you logged in late
- Invalid usernames are restricted from logging in
- Admin must be able to view the attendance and working times of all the users

Additional Features to track Progress 

- track the commits made in git by the user
- update the same to the admin
