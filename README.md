# IncuxAi
# Online Attendance Tracking System

## Overview

The Online Attendance Tracking System is a web-based application designed to automate attendance management in online learning environments. The system records login/logout activity, monitors session status, tracks idle time, and maintains centralized attendance records for efficient monitoring and reporting.

---

## Features

### Student Module

* Secure login authentication
* Automatic login and logout tracking
* Active and idle session monitoring
* Attendance status management
* Student profile and session record storage

### Admin Module

* Real-time attendance dashboard
* Student activity monitoring
* Search and filter functionality
* Attendance history tracking
* Report generation and analysis
